1. Project Objectives & Design Philosophy

The objective of this assignment is to transform my foundational resume website into a refined, editorial-grade digital portfolio built on a Black & Rolex Green Finance aesthetic. Grounded in the philosophy that "a degree is only useful if it has somewhere to land," the website avoids superficial visual noise and dense corporate jargon. Instead, it pairs authentic first-person storytelling with structured financial data tags, crisp typography, and high-readability layout architecture across core sections - Approach, Selected Work, Market Quote, Services Accordion, Beyond the Classroom, Education Ledger, and Contact.

The visual identity merges classic editorial elegance with modern financial market precision:

  • Tri-Font Typographic Stack: Headings feature the classic editorial serif Playfair Display; body text uses the clean, geometric DM Sans for digital legibility; while DM Mono powers kicker tags, ticker items, and data labels.

4. Systematic Use of CSS Selectors (Module 4)

  • Universal Selector (*): Enforces box-sizing: border-box globally, ensuring padding does not distort layouts.
  • Element Selectors: Set base typographic scales, line heights, and margins across semantic tags (body, h1–h3, summary, details).
  • Class Selectors: Reusable atomic components such as .project, .button.primary, .data-tag, and .beyond-card ensure clean modularity.
  • ID Selectors: Direct landmark scroll-targets (#approach, #work, #help, #beyond, #contact).
  • Pseudo-Classes & Pseudo-Elements: ::selection customizes text highlighting to growth green; :hover powers smooth micro-elevations; .service[open] .plus dynamically rotates accordion icons via transform: rotate(45deg).

5. User Experience & Micro-Interactions (UX/UI)

Dynamic interactive features provide instant, intuitive feedback:

  • Interactive Services Accordion: The "Where I'm useful" section employs semantic <details> and <summary> elements with custom plus/close transitions (transform: rotate(45deg)), allowing users to drill into capabilities.
  • Hover Elevation: Project cards subtly transition on hover (transform: translateY(-2px); border-color: var(--green)) with soft drop shadows.
  • Ledger Contact Terminal: The contact section features a 2-column ledger design-pairing left-hand dashed metadata rows with a structured direct message form.
  • Responsive Media Queries: Handled via @media (max-width: 900px), cleanly collapsing multi-column grids into single-column mobile flows while preserving touch targets.
